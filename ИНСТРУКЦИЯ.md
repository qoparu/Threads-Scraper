# Инструкция: Мониторинг Threads по г. Алматы

## Что делает скрипт

`almaty_monitor.py` собирает посты из Threads по теме Алматы за период **1 января — 3 июня 2026**.

- **15 хэштегов**: #алматы, #almaty, #алмата, #алматы_новости, #алматы_события и др.
- **17 поисковых запросов**: «алматы», «алматы новости», «алматы спорт» и др.
- **Фильтрация рекламы**: реклама, скидки, акции, промокоды, распродажи и т.д. (31 паттерн)
- **Фильтрация ботов**: по паттерну имени, количеству хэштегов, повторяющемуся контенту
- **16 категорий**: Новости, Культура, Спорт, Транспорт, Экология, Медицина, Политика и др.
- **Экспорт**: JSON + CSV в папку `output/`

---

## Шаг 1: Получить куки Threads

Threads требует авторизованную сессию для API. Без куки скрипт ничего не соберёт.

### Chrome / Edge:
1. Откройте **threads.net** и войдите в аккаунт
2. Нажмите **F12** → вкладка **Network**
3. Обновите страницу (F5)
4. В списке запросов нажмите на любой запрос к `threads.net`
5. В правой панели → **Headers** → прокрутите до **Request Headers**
6. Найдите строку **Cookie:** и скопируйте всё значение (длинная строка)

### Firefox:
1. Откройте **threads.net** и войдите в аккаунт
2. **F12** → **Network** → обновите страницу
3. Нажмите на любой запрос → **Headers** → **Request Headers** → **Cookie**

---

## Шаг 2: Добавить куки в .env

Откройте файл `.env` (в папке `Threads-Scraper/`) и добавьте:

```
THREADS_COOKIE=<вставьте сюда скопированное значение>
```

Пример:
```
LOG_LEVEL=INFO
THREADS_COOKIE=sessionid=AbCdEf123456; csrftoken=xyz789; ...
```

## Шаг 4: Результаты

Файлы сохраняются в `output/`:
- `almaty_threads_YYYYMMDD_HHMMSS.json` — полный JSON
- `almaty_threads_YYYYMMDD_HHMMSS.csv` — CSV для Excel (UTF-8 BOM)

### Колонки в CSV:
| Колонка | Описание |
|---------|----------|
| id | ID поста |
| username | Никнейм автора |
| text | Текст поста |
| category | Категория (Новости, Спорт, Культура...) |
| like_count | Лайки |
| reply_count | Ответы |
| repost_count | Репосты |
| created_at | Дата/время публикации (UTC) |
| url | Ссылка на пост |
| source | Откуда собран (#хэштег или search:запрос) |

## Категории

Скрипт автоматически классифицирует каждый пост:

- **Новости** — новостные публикации
- **Происшествия** — аварии, пожары, ДТП, криминал
- **Культура** — театр, концерты, кино, выставки
- **Спорт** — футбол, хоккей, турниры
- **Транспорт** — автобусы, метро, пробки, дороги
- **Экология** — смог, мусор, зелёные зоны
- **Строительство** — ЖК, снос, реконструкция
- **Образование** — школы, университеты, ЕНТ
- **Медицина** — больницы, врачи, здравоохранение
- **Политика** — акимат, депутаты, выборы
- **Бизнес** — стартапы, инвестиции, экономика
- **Еда** — рестораны, кафе, доставка
- **Туризм** — достопримечательности, гостиницы
- **Технологии** — IT, цифровизация
- **Развлечения** — клубы, мероприятия, праздники
- **Общество** — горожане, петиции, волонтёры
- **Прочее** — не попало ни в одну категорию

## Что фильтруется

### Реклама и промо (исключаются):
- Слова: реклама, скидка, акция, промокод, распродажа, кешбэк, cashback, sale, discount...
- Хэштеги: #реклама, #ad, #sponsored, #промо, #партнерство...
- Фразы: «переходи по ссылке», «успей купить», «ограниченное предложение»...

### Боты (исключаются):
- Никнеймы вида `ab1234567`, `user123456`, `bot99999`
- Посты с более чем 15 хэштегами
- Повторяющийся/шаблонный контент
- Аккаунты с 0 подписчиков и >500 постов
