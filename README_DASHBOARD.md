# Дашборд акимата Алматы — Data-driven аналитика соцсетей

Публичный дашборд городских проблем на основе **Meta Content Library** (Facebook + Instagram).
Жёсткая очистка от рекламы/заказных/оффтопа. Дизайн — светлый premium-gov. Живые часы (UTC+5).

## Архитектура

```
data/raw/meta/*.csv      → экспорты Meta Content Library (FB+IG, ru/kk/en)
ingest_meta.py           → ЖЁСТКАЯ очистка + лексическая разметка → data/meta_clean.json
grok_filter.py (опц.)    → уточнение топ-N постов моделью xAI Grok
build_dashboard.py       → сборка                                 → public/index.html
deploy.ps1               → публикация на Vercel → публичная ссылка
```

## Как запускать

```powershell
# 1. Положить CSV-экспорты в data/raw/meta/  (уже сделано)

# 2. Очистка + сборка дашборда (бесплатно, ~5–7 мин на 96k постов)
python run_pipeline.py

#    С уточнением топ-1500 постов через Grok (нужен GROK_API_KEY в .env):
python run_pipeline.py --grok

# 3. Открыть локально для проверки
start public/index.html
```

## Как поделиться с другими (публичная ссылка)

Дашборд — статическая страница `public/index.html`. Публикуем на **Vercel**:

```powershell
# первый раз: привязать проект (создаст .vercel/project.json)
cd public
npx vercel link

# деплой в прод → выдаст ссылку вида https://имя.vercel.app
powershell -ExecutionPolicy Bypass -File ../deploy.ps1
```

Полученную ссылку `https://<имя>.vercel.app` можно отправить кому угодно — открывается
в любом браузере без установки. Чтобы обновить данные у всех — повторить `run_pipeline.py` + `deploy.ps1`.

Токеном без браузера:
```powershell
$env:VERCEL_TOKEN="ваш_токен"   # vercel.com/account/tokens
powershell -ExecutionPolicy Bypass -File deploy.ps1
```

## Что чистится (жёстко, ru + kk)

Удаляются: реклама/коммерция (прайсы, телефоны, «жазыңыз», «под заказ», рассрочка, промо),
брендированный контент, дубликаты, слишком короткие/ссылочные посты, посты не про Алматы,
и **оффтоп** — всё, что не относится к городским темам акимата. Остаются только гражданские
темы (дороги, ЖКХ, вода, свет, экология, мусор, застройка, безопасность, медицина, образование,
госуслуги, цены) и явные жалобы. Grok дополнительно ловит **заказные/проплаченные** посты.

## Метрики

Лайки/комментарии/репосты/реакции берутся напрямую из Meta Content Library — **достоверны**,
«фантомных» чисел нет. Для Facebook негатив определяется реальными реакциями (😡 angry + 😢 sad).
